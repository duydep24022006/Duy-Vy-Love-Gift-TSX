# Duy & Vy — Món quà bất ngờ

Trang quà tình yêu tương tác viết bằng React 19, TypeScript (TSX), Tailwind CSS 4 và Vinext/Next.js.

## Chạy trên máy

Yêu cầu Node.js 22.13 trở lên và pnpm.

```bash
pnpm install
pnpm dev
```

Mở địa chỉ được hiển thị trong Terminal.

## Tạo bản production

```bash
pnpm build
pnpm start
```

## Chỉnh nội dung

- Toàn bộ câu chữ và luồng tương tác: `app/page.tsx`
- Màu sắc, hiệu ứng, bố cục responsive: `app/globals.css`
- Tiêu đề và mô tả trang: `app/layout.tsx`

Tên cặp đôi hiện tại là **Duy & Vy**. Hiệu ứng gồm màn mở quà, chuyển cảnh ánh sáng, chữ neon bay trong không gian 3D, tim nhiều lớp và thiệp tình yêu ở trung tâm.
